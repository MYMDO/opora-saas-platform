# Pareto Roadmap: стратегія і план розвитку (живий документ)

> Baza: ADR 0002 (wedge + $0 burn + free-моделі), `docs/research/2026-09-competitor-analysis.md`
> (14+3, матриця X×Y), болі МСБ (кадри 69%, енергетика 82%, 478 людино-днів обліку).
> Правило: не «український Retool», а «One App Free + шаблони + укр. комплаєнс з коробки».
> Оновлювати при кожній закритій фазі. Останнє оновлення: 2026-09-04, 153 тести.

## Де ми зараз (факт)

Ядро готове: DSL + DataPort (Memory/D1, audit+outbox) + metadata (draft/publish/**rollback**/**diff**)
+ workflows (порівняння `== != < <= > >=`, cron-дрен, idempotency, runs-журнал) + Runtime/API/UI.
Шаблони без коду платформи (e2e-доведено): service-desk, inventory, **hr-desk**
(вакансії → кандидати → онбординг, stats-воронка за етапами).

## Фаза A — довіра ✅ закрита

- [x] Атомарний publish (batch), runtime лише з published
- [x] `GET .../releases/:v/diff` — зміни + breaking-ризики до publish (§10 блюпринта)
- [x] `POST .../releases/:v/rollback` — відкат в 1 клік без втрати історії
- [x] Tenant-boundary тести на endpoints, record-RBAC, audit/outbox у мутаціях
- [ ] UI-поверхня diff/rollback у Builder (API готове, фронт — далі)

## Фаза B — перші гроші 🟡 в процесі

- [x] HR Desk-шаблон (бʼє в кадровий біль 69%)
- [x] **Крок B1. Sum-агрегація в DataPort** — `sum` поруч із `count group by`
  (Memory + D1 `SUM(CAST … AS REAL)`), stats-endpoint `?sum=` (лише number-поля,
  400 інакше), sum у stats-view DSL + UI-смуга, тести меж (порожньо/нулі/
  нечисла/негативи-логіка, скоупінг). Розблоковує ПН-сторож.
- [x] **Крок B2. ПН-сторож — шаблон готовий** (без коду платформи): сутності
  `counterparty`/`invoice`, stats `groupBy=status&sum=amount`, workflow-алерти
  (`amount >= 100000`, `status == 'blocked'`); e2e-доказ + live v1 на проді.
  Справжній сторож накопичувальних лімітів (сума за контрагентом ≥ ліміт)
  потребує scheduled-агрегатів — зафіксовано як наступний платформенний крок.
- [ ] **Критерій B2:** 1 бухгалтер-design-партнер каже «за це плачу» (поза кодом).
- [ ] **Крок B3. Укр. пакет дня 1:** НП/Укрпошта (ТТН→етапи), телефонія, Checkbox/Вчасно.Каса,
  КЕП + Дія.Підпис/Шерінг, тригери людською мовою (зразок — Keepin/SalesDrive).
  Критерій: 3 design-партнери на реальних даних.

## Фаза C — монетизація ⏳ далі

- Лічильник runs/resolutions + ліміти планів + мʼякий paywall (freeze, не delete)
- Ціна: platform fee за компанію (2500–6000 грн/міс) + outcome (грн/resolution, грн/лід),
  Free-for-1 + trial 14 днів. Без per-seat податку на viewers (урок Retool).
- EMS-фасад (REST + графік + ROI-калькулятор), не IoT-платформа
- Метрики: NRR, CAC payback <6 міс, churn <10%/міс

## Свідомо НЕ робимо (до перших 10 платних)

PG-адаптер · довільний code-sandbox · SSO/SAML/SCIM · власний бухоблік і AI-моделі ·
бій фіча-в-фічу з Directus/Retool · embed чужих рантаймів без EE-угоди (урок Windmill) ·
залежність від чужої БД без експорту (урок Stacker) · хостинг без exit-шляху (урок Parse).

## Stop-loss (з ADR 0002, без змін)

3–4 тижні в поточному темпі без 3 design-партнерів → міняти wedge, не закривати код.
Нема 3 платних до тижня 12, churn >10%/міс два місяці, CAC >6-місячного чеку → півот wedge.
Найм/офіс/enterprise-продажі — лише після 10 платних.

## Чекліст design-партнера (1 сторінка на інтервʼю)

1. Яку рутину забираємо (кадри / ПН-ліміти / ТТН)? 2. Хто платить і скільки завтра
   (ціль 3500 грн/міс)? 3. Звідки імпорт (Excel/Keepin) за 1 клік? 4. Лист намірів до коду.
