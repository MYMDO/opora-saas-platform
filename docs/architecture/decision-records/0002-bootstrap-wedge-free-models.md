# ADR 0002: Bootstrap-стратегія wedge + розробка free-моделями

- Статус: прийнято
- Дата: 2026-09-04
- Джерела: `docs/research/2026-09-competitor-analysis.md`, `docs/research/Проблеми українців та бізнесу.md`, `docs/research/Аналіз проблем для єдиної платформи.md`, ADR 0001

## Контекст

- Sunk cost MVP = $0 + кілька днів часу. Інфра = Cloudflare Free ($0–20/міс). Найму нема.
- Команда = власник (промпти через OpenCode) + безкоштовні LLM-агенти (DeepSeek V3 Flash, Muse Spark 1.3).
- Ядро готове на ~65% (dsl, data-runtime, metadata, workflow, api 33 тести, runtime-web). Швидкість доведена днями, не місяцями.
- Ринок: червоний океан горизонтальних builder (Retool, Directus, Power Apps, Creatio), але вільна ніша — укр. МСБ + комплаєнс з коробки (ПН-ліміти, КМУ 692/1048, КЕП/Дія.Підпис) + ціна за компанію без per-seat податку. Болі: кадри 69%, енергетика 82%, 478 людино-днів обліку.

## Рішення

1. **Умовне ТАК з wedge, не head-on.** Не «український Retool», а «One App Free + 2 шаблони (HR Desk, ПН-сторож) + укр. пакет + гібридна ціна за компанію». Бій фіча-в-фічу з Directus/Retool заборонено.
2. **Bootstrap-обмеження.** $0 burn: без найму, оренди, enterprise-продажів до 10 платних. Break-even кешем = 1 клієнт (2500–3500 грн/міс). Єдиний ліміт — час власника.
3. **Парето-порядок.** Спочатку довіра (publish/rollback, revisions, tenant-boundary тести), потім 2 шаблони + укр. пакет (НП/телефонія/Checkbox/Вчасно/Дія), потім лічильник runs/resolutions + ROI-дашборд. PG-адаптер, sandbox довільного коду, SSO/SAML — відкладено.
4. **Правила free-моделей.** Вузький контракт за §11 блюпринта на кожну задачу (що робити, заборонені зони, критерій: код + тест + міграція/rollback). Агентам можна: CRUD-шаблони, UI-види, тести межі, міграції D1, шаблони за готовим контрактом. Ядру (auth/RBAC, tenancy, `allow`/`if` evaluator, секрети/підписи, білінг) — тільки з ручним ревʼю власника + зеленим tenant-boundary тестом, інакше не мерджити. Секрети і токени в промпти заборонено. `eval` у DSL заборонено (тільки allow-list AST).
5. **Stop-loss за часом.** 3–4 тижні в поточному темпі без 3 design-партнерів — міняти wedge (наприклад, тільки ПН-сторож для бухгалтерів), не закривати код. Нема 3 платних до тижня 12, churn >10%/міс два місяці, CAC >6-місячного чеку — півот wedge.

## Наслідки

- Downside обмежено вечорами промптів; upside — 30–80 платних МСБ + впровадження 30–80k грн.
- Кожен PR, що торкається tenancy/auth/DLS-виразів/секретів, без review власника відхиляється.
- Ціни/ліміти конкурентів звіряти з першоджерелами щокварталу; цей ADR переглянути при перших 10 платних або зміні burn >$50/міс.
